# Proyecto85 V7.1 — Módulo 1 Nutrición COMPLETO

Esta versión cierra el Módulo 1.

## Incluye
- Menú semanal con rotación y variedad.
- Cantidades y estado de pesado (crudo/cocinado/listo).
- Sustitución de platos e ingredientes.
- Biblioteca ampliada de recetas.
- Recetas propias.
- Foto y enlace de vídeo por receta.
- Puntuación 1–10 y aprendizaje de preferencias.
- Menú que penaliza repeticiones recientes.
- Despensa con cantidades y caducidad.
- Alertas para aprovechar alimentos.
- Lista de compra conectada al menú y despensa.
- Batch cooking.
- Comidas sociales y modo restaurante.
- Registro de hambre, energía, saciedad y digestión.
- Historial nutricional y aprendizaje.
- Indicadores de variedad y grupos alimentarios.
- Actualización automática heredada de V7.0.1.

La información nutricional es orientativa y no sustituye pautas clínicas individualizadas.
